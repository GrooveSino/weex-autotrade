# Aptos 本地钱包

面向 Aptos Mainnet 的本地多账户钱包和批量转账工具。支持 APT、原生 Tether USDt、本地加密密钥、一对多/多对多转账、随机金额、随机间隔、可选 Fee Payer 和执行审计。

## 环境

- Node.js 22 或 24（`@aptos-labs/ts-sdk@7.2.0` 要求 Node.js 22+）
- pnpm 11.15.1（由 Corepack 和 `packageManager` 自动固定）

## 启动

```bash
cd aptos-wallet
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

浏览器访问 `http://127.0.0.1:48272`。API 监听 `http://127.0.0.1:48271`，两个服务都只绑定本机回环地址。

生产构建和单端口运行：

```bash
pnpm build
pnpm start
```

生产页面由 API 服务托管，访问 `http://127.0.0.1:48271`。

## 仅限本机

这个钱包被设计成单机个人工具，不是可部署的网站服务：

- 后端监听地址固定为 `127.0.0.1`，配置为 `0.0.0.0`、局域网 IP、容器外网地址或域名时会直接拒绝启动。
- 网页来源只能是 `http://127.0.0.1:<本机端口>`；Host、Origin、CSRF 和浏览器跨站请求元数据会被同时校验。
- 不要在 Nginx、Caddy、Cloudflare Tunnel、SSH 端口转发、内网穿透、NAS 应用商店、Vercel、Netlify 或 GitHub Pages 后面暴露本程序。
- 没有活动执行任务时，会话空闲 30 分钟会自动锁定保险库；重新解锁会立即作废旧 Cookie 和旧事件连接。
- SQLite 主文件及 WAL/SHM 文件启动时强制设为 `0600`，仅当前系统用户可读写。仍应开启系统磁盘加密并锁好电脑账户。

代码无法阻止拥有本机系统账户和管理员权限的人主动建立外网隧道，也无法在操作系统已被恶意软件控制时保护屏幕、剪贴板或进程内存。因此不要把它运行在共享主机、云服务器或不可信电脑上。

## 主网门禁

默认只允许查询、编辑和预览。启用真实 Mainnet 提交必须在启动前显式设置：

```bash
export APTOS_MAINNET_EXECUTION_ENABLED=true
pnpm dev
```

使用本机 LaunchAgent 时，必须显式带上启用参数：

```bash
pnpm build
./scripts/install-launch-agent.sh --enable-mainnet
```

每个任务仍必须完成余额预检、交易模拟、保险库解锁，并输入页面生成的完整确认短语。交易提交不会自动重试；传输异常会按预计算交易哈希查询链上，无法确认时任务进入 `uncertain`。

## 主网查询保护

- 所有余额、账户状态、交易模拟和交易哈希查询共享一个进程级调度器：最多 2 个并发请求，启动间隔至少 200ms，硬上限约 300 个请求/分钟。
- 429 会读取节点的 `Retry-After`；没有该响应头时也会自动退避，连续限流会指数延长冷却，最多暂停 60 秒。
- APT 余额响应会缓存账户存在状态 5 分钟，避免每次刷新额外请求 `accountExists`；余额刷新仍会继续获取最新 APT/USDt 数值。
- 前端手动刷新、钱包组刷新和后台自动刷新共享账户级锁，后台默认每 30 秒启动一轮；上一轮未完成时不会重入。
- 这个保护上限刻意远低于匿名公共节点报错中的 `4000`，不会通过压测去探测或消耗公共节点额度。需要更高吞吐时，应配置自己有额度的 Fullnode，而不是提高本地上限。

## 密钥与备份

- 主密码使用 `scrypt` 派生密钥，随机 DEK 和钱包材料使用 AES-256-GCM 加密。
- SQLite、WAL、`.env`、日志和备份文件均已在项目 `.gitignore` 中排除。
- 应用不会自动生成明文私钥文件。助记词和私钥查看均需重新验证主密码和完整名称，并通过一次性 RSA 公钥加密传给浏览器。
- 创建钱包时必须完成 24 词助记词的离线备份和随机词位确认；之后应下载加密保险库备份。
- 丢失主密码后无法恢复保险库；数据库文件不能代替主密码备份。

## 钱包与账户

- 一个钱包由一组助记词保护，钱包里可以添加多个账户，每个账户都有自己的 Aptos 地址。
- 新钱包默认创建第一个账户，可继续添加新账户，或按账户编号找回以前使用过的账户；单次最多处理 200 个。
- 仅凭助记词恢复时，应用不会扫描 Mainnet 猜测用过哪些账户。加密备份会保留完整的账户清单、名称和历史。
- 高级信息：账户使用标准路径 `m/44'/637'/{accountIndex}'/0'/0'`，账户编号范围为 `0..2,147,483,647`。
- 助记词只加密保存一次；各账户的私钥仅在签名或单独查看时临时生成。钱包和账户归档后不会物理删除，已用编号也不会自动复用。
- 归档钱包只需手动确认完整钱包名称；从归档列表恢复钱包或账户时必须重新验证主密码。

## 资产

- APT：8 位小数。
- 原生 USDt：6 位小数，固定元数据对象 `0x357b0b74bc833e95a115ad22604854d6b0fca151cecd94111770e5d6ffc9dc2b`。
- 不接受 LayerZero、Wormhole 或其他同名桥接 USDT。
- 随机金额统一按 `0.01` 的最小步长生成，输入超过两位小数会在预览前拒绝；固定金额仍按资产自身精度校验。
